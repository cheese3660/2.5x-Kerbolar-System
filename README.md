# 2.5x-Kerbolar-System
This is a 2.5x rescale mod for KSP2 Redux.

Redux's whole galaxy, Drast and Beyl included, at 2.5 times the size, as its own galaxy and campaign pack. Pick the
"2.5x Kerbolar System" campaign pack when starting a new campaign. Redux's normal galaxy is left exactly as it is.

Everything is one Patch Manager Lua file, `KerbolarUpscale.lua`, built on Redux's body, part and campaign pack layers.
The Redux modding docs walk through it as a worked example.

Requires KSP2 Redux. Versions before 0.5.0 were patches for the stock game.
